# Contribuindo

Use uma branch e descreva problema, mudança e verificação. Preserve separação entre autorização, recuperação, provedor e ferramentas. Adicione teste negativo para qualquer mudança de acesso. Não versione credenciais, dados reais, modelos ou diretórios gerados.

Execute `python -m pytest backend/tests -q` e `npm run build` em frontend. Modificações de comportamento devem atualizar README e limitações. Use dados sintéticos e não apresente resultados de simulação como operação real.

# Segurança

Este é um laboratório com dados sintéticos, credenciais públicas de demonstração e sem SLA de segurança. Leia [o modelo de ameaças](docs/04-security.md) antes de conectar qualquer fonte.

Não publique credenciais, documentos internos ou detalhes de uma exploração contendo dados sensíveis em issues públicas. Para um relato público, use somente uma reprodução sintética. Use o recurso privado de reporte de vulnerabilidade do GitHub se estiver habilitado no repositório.
